# UniPulse — Decision Intelligence for Indian Higher Education

A decision intelligence platform for Indian higher education built in Next.js (App Router), featuring verified institutional telemetry, NIRF placement audit records, transparent fee benchmarks, and side-by-side college benchmarking.

## 🚀 Features

- **Institutional Directory**: Search, filter, and sort 45+ premier engineering and management institutes by state, governance type, rating cutoff, and annual budget.
- **Side-by-Side Decision Matrix**: Compare up to 3 institutions simultaneously with automated leader highlights across placement CTCs, tuition, and student satisfaction.
- **Comprehensive Dossiers**: Multi-year (2022–2024) placement telemetry, audited degree programs catalog, student ratings breakdown, and interactive review publishing.
- **Candidate Dashboard**: Curated shortlist of bookmarked institutes and saved comparison sets.
- **NextAuth Authentication**: Credentials login with instant 1-Click Evaluator Demo (`demo@unipulse.edu` / `Password123!`).

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Styling**: React 19, Tailwind CSS, Lucide Icons
- **Animations**: Canvas Confetti
- **Authentication**: NextAuth.js (JWT strategy)
- **Language**: TypeScript

## 📦 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
npm start
```
